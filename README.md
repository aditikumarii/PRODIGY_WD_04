
# Personal Portfolio Website

A modern, responsive personal portfolio website built as part of the **Prodigy Infotech Web Development Internship — Task 04**.

## ✨ Features

- 🎨 Modern dark theme with an editorial design
- 👩‍💻 Custom SVG avatar illustration
- 📱 Responsive layout for desktop, tablet, and mobile
- 🚀 Project showcase with interactive preview designs
- 🛠️ Skills and expertise section
- 🎓 Education section
- 📩 Contact section with social links
- ✨ Scroll reveal animations
- 🍔 Mobile-friendly navigation menu

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- SVG Illustration

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/aditikumarii/PRODIGY_WD_04.git
   ```

2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the **Live Server** extension.
